Setup

jChat+ is a Twitch, Kick and YouTube chat overlay for OBS, XSplit, Meld, Streamlabs Desktop and any other streaming software that supports browser sources. It supports BetterTTV, FrankerFaceZ and 7TV emotes, Twitch badges, Kick badges and emotes, YouTube Live Chat messages and custom emoji, smooth message animation, message fading, custom fonts, shadows, strokes and more.

Use this setup page to generate a browser source URL. You can combine Kick or YouTube with Twitch in the same overlay.
